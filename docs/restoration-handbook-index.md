## 3. 总平面：不重排校园，但不沿用错误比例

### 保留与校正

原图保留SHA-256：`a29b9dca5cfd5cce4b38ddeef752989c2f8b38280c8ab04592293cff97b98f08`。原生像素为 **1548×1095**；界面显示缩放尺寸不能当成原文件尺寸。

保留用户已经确认的关系：主楼左侧相连厕所；3×2篮球场；篮球场与其旁跑道平行且紧贴；跑道左侧体育辅助用房；音乐教室在馆后和跑道旁；泳池左厕；左侧主席台；旗台附近沙坑；校门右侧校名石。

旧图存在一项编号冲突：U9把篮球场06的平行关系写给08田径跑道，而音乐教室24关联05风雨跑道。用户后续确认了紧贴和辅助用房，但没有直接给该跑道编号。**不能继续把这一处当成已经核实的坐标。**

本次三张总图分别是：

1. 原图，供版本对照；
2. 审查覆盖层，标明原图尚未满足的相邻关系；
3. 条件性局部订正v0.6-R：暂将篮球场旁跑道绑定05，只平移06、延伸05的示意条带、补28功能符号。其他建筑足迹不重排。绑定05属于工作假设，不是新发现的历史事实；若核实应为08，撤回局部补丁再处理。

中机国际2023年项目说明确实记载**老训练楼首层为架空直跑道、侧墙有镂空砖**。它提供了重要的旧馆附属空间线索，但不能独立证明2006—2010全部房间位置或旧图编号。[S05]

28是体育辅助用房的工作编号，记录健身/锻炼、体育教师办公室、运动器材三类功能。它不是确定的三栋建筑，也不预设分间、层数和门窗。音乐室与28先分开登记，物理建筑从属仍待核。

### 已做的比例检查

原图首排单片篮球场可见边线中心读数约 **23×43像素**，次排约23×44像素，读数容差约±1像素。首排长宽比43/23≈1.870。与28/15≈1.867比较，只能说该小符号大致符合标准球场比例。

28×15米来自FIBA 2024规则，**只作为条件参照，不证明雅礼当年采用这一实测尺寸**，更不能据此回填当年线位。条件计算的首排横向比例15/23≈0.652m/px、纵向28/43≈0.651m/px不是全校比例尺。现有实测控制点数量为0，全局米制比例未建立。[T12]

### 下一步的尺度工作

选固定墙角和台阶端点，获取不平行的长度、楼间净距、分段和对角线；保留原始重复读数。控制点与独立检查点分开。QGIS拟合后保存变换参数、残差和异常点理由，不以任意拉伸抹平年代或布局冲突。树冠、临时篮球架、移动锥桶不作稳定地面控制点。[T07]

## 5. 绿化与校园物件

绿化不是在模型完成后随机撒树。为主路乔木、入口树池、旧图书馆藤本、后花园和体育馆前植被建立5类观察对象，记录原图、年代、可见冠幅、分叉、树池边界与邻楼关系。当前不凭远景给出树种或胸径。

物件按18类记录：伸缩门、牌匾校徽、校名石、围墙灯杆、门窗防护栏、空调管线、雨棚入口柱、垃圾桶告示架、课桌椅、黑板讲台、吊扇灯管、电视广播、食堂桌凳、球架篮板、看台扶手、健身器械、器材柜架、旗杆旗台。

其中已制作伸缩门、自然石、食堂桌凳和篮架的实拍细节裁片＋可见结构标记。缩放、裁切与叠线明确说明。器材库、健身设备型号没有图就留空，不以其他学校的器材填满雅礼。

每件未来资产都需区分可移动/固定、安装点、材料、年代、重复数量、尺度来源和照片角度；不从一张经白平衡/曝光处理的照片宣称取得了真实材料颜色或PBR参数。

## 6. 数字化案例转化为本项目工作步骤

### CyArk Bagan：不同时间、不同尺度分开记录

公开任务记录区分场址GIS与重点建筑的精细资料，并保留不同阶段记录。这里借鉴的是区域—建筑—细部的组织方法，以及正射/剖面/图像资料各自的用途，不把后期资料覆盖旧校园。[T03]

### HABS与Historic England：草图不是实测图

照片、文字和图纸共同交付，区分可测、推定与缺失部分。总图的每次修改保留原件、操作记录和判断依据；独立检查点不参与拟合。米制测绘应有控制和误差报告，本册尚未完成这一步。[T01/T02]

### Campus3D / NUS：对象编号不能丢

校园点云研究使用分区、语义和实例标签。对雅礼适用的是为楼、树、栏杆和设备分别设稳定ID，确保某棵树或一段跑道的修改可以被追踪。该数据集属于他校数据，不搬用其模型作为雅礼复原。[T05]

### NUS绿化数字化：现场树木数据与空间资料结合

其公开资料说明绿化模型综合卫星影像、校园扫描和大树地面量测。这里借鉴树木清点、同株编号和阶段对比；不引入微气候传感网、实时运维和能耗平台。[T06]

### NPS/CyArk低成本采集：先试采，再扩展

简单相机、测距与现场表单即可建立有效采集流程。先在体育馆和一段走廊检验点号、照片顺序、尺度记录和交接是否可复用，再覆盖全校；不用先购买昂贵扫描设备，也不按旧文章价格做当前预算。[T04]

## 7. 工具与必要记录

| 工作 | 工具 | 产物与限制 |
|---|---|---|
| 整理原图 | 文件命名、SHA-256、ExifTool | 原图不改；保留EXIF与原作者，EXIF不是不可篡改证明 |
| 二维分析 | 矢量编辑工具、图像编辑器 | 原实拍层、标注层、尺寸层分别保留；不是三维成果 |
| 总图校准 | QGIS＋CSV/GeoPackage | 有控制点才配准，输出变换和残差 |
| 现场记录 | 已有手机/相机、卷尺或激光测距、三脚架、尺度板 | 端点照片、重复读数、高差、采集日期 |
| 相机匹配 | fSpy | 后续辅助照片机位；一张照片不能自动生成真实背面 |
| 多视角重建 | COLMAP | 仅在资料合格且进入建模阶段后考虑；本轮未运行 |
| 点云比对 | CloudCompare | 获得真实扫描数据后才使用；不以ICP掩盖年代差异 |
| 协作交接 | Git、PDF、结构化台账 | 稳定ID、变更记录、问题关闭和审核者 |

补拍要求：外部正面/两侧/背面/入口/环境；同室四角、门外反拍、顶棚和地面；楼梯上下端与平台；同株树四面及基部；物件安装点和尺度。照片组应包含相机位置的移动和重叠，不只站在原地旋转。[T09]

现场量测表必须有对象ID、年代、A/B端点、单位、重复读数、仪器、是否斜距、误差来源、采集人和复核人。缺失数字保持空值，不写0。

## 8. 进入精模之前的关口

当前可用来继续研究：门架的可见形体、体育馆正斜面及内部空间线索、长雅入口、旧图书馆入口、科学馆入口和部分室内、食堂大厅、教室陈设、林荫道和物件。

必须先补的P0：跑道编号绑定、28用房功能与实际分布、15—25逐层连接、至少一组稳定控制点与尺寸链、旧体育馆背面与剖面。其余缺图按照设施登记逐项补齐。

手册全面覆盖已知对象，不等于全部视角和尺寸齐备。**没有提供全校实测1:1成果、全楼四向照片组或完整房间平面。** 这些状态不应在下一轮被自动改成完成。
