## 已确认关系与工作推定

- 保持原01—28编号、坐标原点、米制工作单位以及无关区域。实际变动位置或外包尺寸的设施只有02、03、23、25、26；其余设施位置和尺寸保持。
- 05有顶棚、06为3×2且共边；28仍低矮单层。
- 24仍是四层独立体块，独立体块**不等于不连通**；本轮以独立接驳对象连接03和24，不与28合并。
- 25在15左侧，每层相连、入口朝15。本版将草图注册为两者相向端墙中线接入；不将25搬到教学楼背后。首层平接与地面穿行十字交叉，上层桥下留净空，这是当前构造工作方案，不是实测剖面。
- 沙坑只有一个23；旧前坪右端坐标废弃，以后缘橡胶直段右端为准。
- 26是更小的历史厕所，不把圈注内后期玻璃体量照搬成旧貌。

| H参数 | 旧值 | 本轮工作值 | 限制 |

| 03体育馆包络 | 30×36m | 42×42m，高度仍15m | 按校友更大体量要求选取，非照片测量 |

| 后缘橡胶直段 | 无独立直段 | 92×7m，23置于右端 | 长宽、线位不是现场实测 |
| 02侧门与小路 | 门旁未核标记 | 主路分支沿操场右侧至新工作端点 | 小路拓扑A，门的精确落点、弯折和宽度H |

本版不会宣布测绘1:1通过，也不会把该次工程修复关闭等同为校友最终空间验收。

## 真正修改的工程文件

- `data/m10/layout-input.json` → 生成`campus-layout.json`；主要足迹与新增场地要素分别导出。
- `apps/campus/src/revision-core.mjs`：顶棚/连接等物理部件数据、解析路线检查、R2约束。
- `apps/campus/src/revision-scene.ts`：真实顶棚几何、建筑开口、折面体育馆、连桥与橡胶直段。
- 既有`main.ts`/`layout-core.mjs`：接入修订，不保留错误绕行或旧沙坑。
- `tests/m10/layout.test.mjs`：新增错误注入回归。
- `tools/m10/capture-r2.py`：实际浏览器、实际Mesh的路线/入口检查和多视角截图。
- `data/restoration/assumption-register-r2.json`：工作参数与历史事实分开。

`tools/m10/repair-r2.py`和`.github/m10-r2.patch`是可审计的一次性迁移，首次CI应用后，将生成的真实源码和数据提交回仓库。不是只提交一份计划或让查看器运行时猜测坐标。

## 验证与查看

以`qa/m10-r2/browser-report.json`、`route-mesh-probes.json`和本轮Actions状态为准；旧`qa/m10`截图是前版记录，不能证明R2已通过。浏览器测试使用Chromium软件WebGL，验证渲染和操作正确性，不认证真实设备帧率。

本地运行：

```bash
python tools/m10/generate-layout.py
cd apps/campus
npm ci
npm test
npm run build
npm run standalone
```

首次应用迁移的步骤记录在`.github/workflows/m10-build.yml`。在已修复源码上无需再次手工迁移。

新增机位：球场看馆、棚下、后缘跑道、图书馆通路、两楼间穿行和侧门小路。设施面板中的“顶棚/接驳屋盖”只改变可见性，不移动任何设施。

M1.0仍是空间骨架；完整人物碰撞、所有楼层楼梯、精细内装、体育馆准确隐藏面留待后续M1制作。当前自由校核与路线巡览不等于完整游戏。
