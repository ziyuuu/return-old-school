## 局部修改

10工作Z132→110；20中心(166,82)→(172,74)，60×104m包络及六个H子楼体保留。右移6、上移8后与食堂工作间隙15m，旧R3恰好7m目标由本轮要求替代，没有恢复45m空白，也不移动食堂掩盖问题。其余26项设施位置尺寸、原点轴向保留，25在原占地内重构。

绿色绕行三个节点及实体铺装删除，19花园保留，未知入口不编造。主路原来按节点名推断宽度导致末段回落3m；现在主干显式7m连续。所有数值H。

黑线分别按16东侧支路、14前庭至15正门、15东端至21西侧短接路落实；交叉点分段入导航图，门前铺装对应真实开口，15后门至18、15与25间穿行保留。

## 每层厕所构造

移除原来的双独立体块与中央贯穿槽。25改为连续楼体，正常内部隔墙分区；桥接面向主楼的前廊中部，沿前廊向两端门走。每个入口朝向教学楼，不在桥后中央槽深处。

按当前15的四层H设置生成四张整幅楼板，覆盖内部和前廊，与对应连桥标高一致。前廊外侧及端部均为真实护栏和立柱；桥侧留2.4m H开口。不是只首层有地面，不是用线条冒充楼板。男女哪一端未确认，入口用A/B表示而不伪造历史方位。

新增“厕所逐层”机位及工作台楼层选择，隐藏所选层以上的楼层和屋顶；只改变显示，不移动设施。卫生器具、结构配筋、全校楼梯及精细内装不是本轮交付。

## 同步与验收

`layout-input.json`为当前输入；`baseline-r3-input.json`和`revision-r4.json`保留变更前后。H值在`data/restoration/assumption-register-r4.json`。核心部件和断言在`revision-r4-core.mjs`，实际几何在`revision-r4-scene.ts`。原有README、开发计划、设施表、约束和导出同步。

`docs/plates/masterplan-m10-r4.svg`从同份坐标及实际道路宽度输出。`qa/m10-r4`为本轮实际WebGL截图、路面/门洞/逐层地板探测和构建记录；不用旧截图证明新代码。回归清单由成功报告生成至`docs/m10/regression-r4.md`。

首次CI应用透明数据迁移和显式源代码编辑，并保存源代码diff。成功后提交真正源文件和生成数据；重复运行不重复移动。工程测试不等于校友最终验收、测绘或完整物理角色。

运行：仓库根目录执行`python tools/m10/generate-layout.py`，然后`cd apps/campus && npm ci && npm test && npm run build && npm run standalone`。M2夜景及具体玩法不在本轮。
