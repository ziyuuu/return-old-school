## 冻结的主要空间事实

1. 校园设施编号体系继续使用 01–28；未定位对象不为凑数而虚构位置。
2. 主门、侧门、校名石关系按 R4 总图冻结；侧门路在入口区域不与主门主路错误直连。
3. 六片篮球场为 3×2，与有顶棚的 05 直跑道平行且紧贴；28 体育辅助用房为低矮单层。
4. 08 田径场保留操场后缘橡胶直段；23 沙坑位于该后缘右端工作位置；10 主席台采用 R4 上移后的工作位置。
5. 24 音乐楼为四层独立设施体块，与 03 旧体育馆本体直接贴合，不保留外加连接楼梯/连廊的 R2 假设。
6. 25 主楼厕所位于主教学楼图面左侧，每层与主楼中部相连；厕所为连续楼体，每层有完整楼板和门前走廊，两端入口朝主教学楼，桥侧护栏留通行缺口。
7. 主楼与厕所之间地面可穿行到旧图书馆；主楼后门与图书馆保持连接。
8. 17 长雅楼采用 R4 工作位置，道路直接对准正门；绿色标注的错误绕行路已删除。
9. 20 家属区采用 R4 右上移动后的工作组团，并保持与食堂较紧密的外部体量关系；不包含私人住宅内部。
10. R4 黑线补充的三处短路以及红框主干连续宽度作为当前道路基线。

## 变更规则

从 M1.1 起，`baseline/m1.0-r4` 作为只读参考基线。后续开发在 `main` 上推进。

只有出现 **baseline-breaking evidence** 时才允许重新讨论 M1.0 冻结项，例如新证据证明某栋主要建筑位置、核心道路拓扑或已确认设施关系存在实质错误。窗格数量、局部门位、栏杆、树木、材料、层高微调等属于 M1.1/M1.2 精化，不重新打开 M1.0。

如需修改冻结事实，应创建新的 GitHub issue，明确：新证据、受影响设施、与 R4 的差异、是否需要升级基线版本。不得静默覆盖本分支。
