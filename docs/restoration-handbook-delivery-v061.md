## 3. 总平面不能把“比例校核”写成“完成测绘”

原图基线仍为 1548×1095 像素，SHA-256 `a29b9dca5cfd5cce4b38ddeef752989c2f8b38280c8ab04592293cff97b98f08`。本次保留基线和既有 v0.6-R 局部关系方案，不重排校园。

篮球场符号首排边线中心读数约 23×43 像素，容差约 ±1 像素。与 FIBA 2024 的 28×15 米形状比例比较仅是条件性检查，不能证明雅礼当年的实际尺寸，更不能定全校园比例尺。

**当前实测控制点为 0，全局米制比例未建立。** 下一步需要固定墙角、台阶端点、非平行长度、对角线和高差链；拟合数据与独立检查数据分开记录。未知尺寸保持空值。

篮球场旁跑道的 05/08 编号冲突仍开放：原图 U9 使用 08，音乐室关联 05；v0.6-R 暂绑定 05，仅为可回退假设。以下用户确认关系不因此撤销：六片 3×2；球场与相邻跑道平行且紧贴；跑道图面左侧有健身、体育教师办公室和器材空间；音乐室在馆后和跑道边。

体育辅助用房不是已经核实的三栋独立建筑。音乐室和辅助用房分开登记功能，物理从属、层数、房间顺序和门窗继续核查。

## 4. 多视角与“还原图”的边界

本版还原依据图是**实拍上的构件编号、局部裁片和可见层次分析**，不是新绘制的未知背面、自动修复的历史照片、测绘立面或游戏实机截图。

重点特征包括：校门不对称门架与高门墩、自然校名石；旧馆折面、中央面板、退窗、长平台和外梯；旧主楼后坪；长雅楼玻璃凸部、弧形雨棚和曲线台阶；旧图书馆红框门与藤本；科学馆入口与镂空砖；食堂长桌蓝凳及柱网。

部分设施仅有入口单向或口述，均明确列缺图。不得以新主楼补旧主楼，不得以不同教室照片拼成已验证的同一房间，不得用生成图补齐屋盖、背面或楼层连接。

## 5. 案例带来的必要流程

- [Historic England 测绘规范](https://historicengland.org.uk/images-books/publications/geospatial-survey-specifications-cultural-heritage/)：控制、误差、成果规格与交付限制。
- [NPS 建筑记录标准](https://www.nps.gov/subjects/heritagedocumentation/soi-standards-guidelines.htm)：图纸、照片、文字及可靠来源相互支撑。
- [NPS/CyArk 低成本记录](https://www.nps.gov/articles/000/preserving-heritage-with-low-cost-documentation.htm)：相机、尺度量测、试采和可操作指南；不引用旧价格作为当前采购预算。
- [Campus3D](https://3d.nus.app/blog/release/)：区域、语义类别和对象实例编号；不意味着复制 NUS 模型。
- [NUS 绿化数字化](https://uci.nus.edu.sg/campus-sustainability/dematerialise/)：树木作为可记录对象，结合扫描/遥感和地面量测，而非随机布树。

本阶段实际使用文件哈希、CSV/JSON、二维标注、PDF 与索引。QGIS 待控制点取得后用于配准；fSpy、COLMAP、CloudCompare 分别服务于后续机位、多视角重建和点云配准，不是本轮已运行的工作。
