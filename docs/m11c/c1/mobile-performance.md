# C1 R1.2 · 手机端性能修订

工程状态：IMPLEMENTED / REVIEW_PENDING。用户确认 R1.1 控制功能基本没有问题，同时指出手机明显卡顿。此次反馈记在 `data/m11c/c1/review-feedback-r11.json`，不伪造实体手机性能认可。

## 实施

1. 对校园非索引网格做全属性逐位相等的顶点复用。位置、法线、UV 不四舍五入，不减三角面、不改绕序或门洞；碰撞/BVH仍读取同一真实三角面。
2. 同一驻留覆盖范围内保留原 Rapier 碰撞体，进入新区域只创建覆盖不足的源网格；重复选择同一出生点不再重建两次。保留原26m覆盖与9m切换规则，不缩小角色或放宽通行。
3. 漫游时缓存静态校园矩阵；人物/相机/太阳矩阵显式更新。回到建筑审阅恢复通常的矩阵更新。
4. 行走阴影焦点采用6m水平/3m竖向迟滞，保留近景28m半幅覆盖；新几何/显隐/画质变化仍失效更新。不每半米重拍静态校园。
5. 手机新加载默认“流畅”：内部像素比1、1024阴影，持续慢帧时逐档最低0.75。DOM界面保持原分辨率。帮助面板可切换“完整清晰”，恢复最高1.5像素比、手机2048阴影。横屏触摸设备同样走手机分支。
6. 不要求WebGL保留旧绘图缓冲；截屏由同一实际绘制后的画面获取。隐藏的建筑标注不在漫游每帧重新投影和写DOM。

## 标准边界

继承美术标准v1.0；唯一画质参数偏离是可逆手机栅格预算与行走阴影缓存策略，见标准附录 mobile-r12。22组色板、17类材质、日光曝光、反射探针、深度兼容、校园形体、树木精度、人体胶囊、坡速与方向映射不改。没有bloom/暗角/景深，无原照贴图。

新文件 `Yali_C1_R1_2_Viewer.html` 与 `viewer-manifest-r12.json`；旧R1/R1.1保持原样。QA在 `qa/m11c-c1/mobile-r12`。最终数字由实际浏览器报告填写；开发机器或SwiftShader数据不是用户手机帧率。

技术参考：Three.js WebGLRenderer / LightShadow / Object3D 官方文档。当前依赖版本仍按package-lock固定，未更新图形库。
