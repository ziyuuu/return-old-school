# C2 R1｜学生形象与基础动画

状态：**IMPLEMENTED / REVIEW_PENDING**。继承 C1 R1.2 手机优化、碰撞、坡速、相机与已认可校园几何。

## 证据与美术

公开“100张老照片”整理页引用09届校友资料：当时秋季校服常故意买大尺码，裤脚盖住鞋面；同组资料称藏蓝 logo 文化衫是“后来逐渐”成为夏季上衣。因此 C2 默认采用**偏大尺码秋季运动校服工作重建**，不把后来文化衫强行推广到整个2006—2010，也不虚构校徽、班级、姓名或涂鸦。精确分色、剪裁、体型、发型继续 H。

程序化模型继续使用共享材质工厂、48段主要圆弧和低饱和校园色系；没有外部人物照片纹理、bloom、暗角或额外人物灯光。人物不参与静态建筑阴影重烘焙，保留接地影近似。

## 动画

同一关节模型提供 idle / walk / run / air 四态；状态由真实胶囊速度和接地状态驱动。walk/run 使用实际旅行距离推进相位，避免低帧率下脚步与位移完全脱节。C2 不引入跳跃、交互动作或剧情。
