## 范围与风格依据

保留白翻领、蓝上衣与宽松蓝裤、胸袖上白下红横带、左胸 YL、短黑发和白鞋。重建连续棱面短发、简化方眼、几何鼻梁、克制嘴线，以及分区明确的衣袖、裤腿与闭合鞋楦。去掉虹膜/瞳孔/眼部高光、圆滑发束、鞋带微雕和布料细噪点。头脸、轮廓与颜色采用用户最新参考的块面语言，不是仅给原 R2 模型打开 flatShading，也不是通过随机三角着色伪造低模。

标准：v1.0 + mobile-r12 + 本轮角色限定的用户指示。优先级由 AGENTS.md 的“用户后续明确指示优先”确定。本次重新拓扑为角色风格修复，非未经要求的性能减面；不减少校园面数、不改校园材质与光照。各完整多边形拥有一致的显式法线，GLB 与实际页面使用同一组法线和几何。人物材质复用共享工厂的独立克隆，再去掉角色表面贴图、微起伏、绒光和镜面高光；保留同一日光与物理明暗，不引入单独人物灯、三档覆盖着色、照片贴图或后期滤镜。
