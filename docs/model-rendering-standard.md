# 校园模型、材质与渲染统一标准

版本：1.0 · 2026-09-12。适用于后续 B04/B05、新增环境构件，以及既有模型的局部修订。依据模型与日光首轮升级、材质精化第二轮的最终实现整理；作为后续实施和工程验收的共同依据。

## 1. 使用与变更

开始建模前阅读本标准，先复用共享模块，再实现本批构件。交付说明必须注明采用的标准版本及偏离项。历史交付记录描述当时结果，本标准规定今后的做法；建筑认可仍以各批 acceptance 记录及用户后续指示为准。

文中的“必须／不得”为共同约束；数值表为当前同尺度构件的默认基准，不是所有物件统一堆面数的配额。不同尺度或新材料需要调整时，在本批记录调整原因、参数、同机位画面及相关验证。共同参数的调整须同步修改共享实现和本标准，不能仅在某栋楼内隐藏覆盖。常规实施和已有授权范围内的调整可直接执行，不另设逐项确认流程。

## 2. 美术与历史空间约束

1. 优先级：真实校园复原 > 建筑与环境精度 > 白天校园漫游 > 夜间覆盖层。当前模型工作不自行扩展为剧情、谜题或玩法。
2. 延续柔和、低饱和的校园风格：暖灰／米白墙面、冷青玻璃、灰色结构件、深浅绿植及暖褐种植土。材质可辨认，整体仍属于同一套色彩体系。
3. 使用程序化颜色和表面纹理；不得使用外部照片作为场景贴图，不添加 bloom、暗角或景深来掩盖模型与光照问题。照片仍可作为建模证据和私下审阅资料。
4. 保持已认可的建筑位置、体量、层数、入口方向、桥接关系和地坪高差。不得为建模方便重排校园，也不得用倒角、细分或贴图封堵真实开口。
5. A/P 证据与 H 工作参数分别记录。倒角半径、表面微纹理、精确叶形等视觉补全仍属 H；增加细分不能提升其历史证据等级。
6. 当前关键不变量：田径场—中央国旗—主楼—旧图书馆共轴 x=73；主楼首层 y=3.45；三个旗位；主楼卷帘开口位于内退门廊侧返墙且默认收起。只有用户新指示或相应空间修订任务可以改变这些约束。

## 3. 几何精度

“优化面数”在本项目当前要求下指提高有效几何精度。新增面数应改善轮廓、圆截面、倒角、叶片形态或近景光影；不得把未经要求的减面当作本项任务成果，也不靠细分平墙、平地来凑数量。

### 3.1 实体、尺寸与接合

- 统一使用米制世界坐标。保留模型数据、场景适配器、材质工厂之间的职责边界。
- 门、窗、卷帘入口、桥接通路必须使用真实开口；楼板、踏步和入口支撑面必须连续。不得用透明贴图假装可通行洞口。
- 渲染、拾取、阴影和当前通行校核使用同一份实际几何；不得用简化代理通过测试、同时交付被堵住的可见模型。未来若引入人物碰撞体，应另行说明和验证其与可见模型的一致性。
- 倒角必须按实际构件尺寸生成并位于原包围范围内。不得非均匀缩放圆角单位盒来拉伸窗框、栏杆等构件的倒角。
- 不对平墙的人工分区、踏步顶面及相邻楼板接合边统一倒圆，以免出现假砖缝、漏光或踏步缝隙。

### 3.2 同尺度构件默认基准

| 构件 | 当前默认精度／限制 |
|---|---|
| 金属框、栏杆、百叶等盒状构件 | 倒角分段 3；半径不超过 0.008 m，且不超过最短边的 14% |
| 门扇、门框及木作式收边 | 倒角分段 3；半径不超过 0.006 m，且不超过最短边的 8% |
| 柱、梁、檐口、雨棚等混凝土构件 | 倒角分段 4；半径不超过 0.035 m，且不超过最短边的 8% |
| 极薄构件 | 算得半径小于 0.0002 m 时保持精确盒体；不强行倒角 |
| 近景圆形杆件 | 圆截面 48 段 |
| 体育馆尺度圆环 | 管截面 32 段 × 环向 192 段 |
| 主楼尺度穹顶与圆柱 | 穹顶 96 × 48 段；圆柱圆周 96 段 |
| 主楼中央浅弧 | 沿原曲线采样 256；保持原开口、端点及楼层关系 |
| 花园圆台与池缘 | 沿原轮廓采样 192；不改变梯级、平台位置和外轮廓定义 |
| 爬藤近景叶片 | 当前薄叶为 60 段轮廓、4 层径向环、双面实体，共 840 三角面；保留原覆盖范围 |
| 简化树冠 | 当前使用 IcosahedronGeometry detail=4；保留既有简化体量风格，不将树冠全部替换为高光球体 |

倒角角色可能重叠，实际分类顺序以共享 `bevelProfile` 为准。新角色必须核对结果；名称里含有“frame”不能代替对构件实际材质和用途的判断。几何轮廓确有不同的物件应按其形态建模，不机械套用穹顶或叶片模板。

## 4. 材质标准

### 4.1 先确定用途，再匹配材质

必须使用共享 `surfaceMaterial(base, role, shape)` 与 `resolveFinish`。同一色板行不能被视为同一种物质：玻璃与水、金属与楼板、草叶与种植土必须分开。

新角色应加入集中映射并检查典型混淆项：`window` 是玻璃，`window-frame`／`window-grille` 是框栅，`window-sill` 是实体窗台；`planting` 的叶片与土壤盒体不可混用材质。不得用宽泛的名称子串把整个窗周构造变成透明玻璃。

### 4.2 17 类表面的统一起点

以下为 v1.0 工厂中的基础系数。粗糙度还会乘以对应表面贴图；微起伏为着色强度，不是几何位移或实测孔深。

| 标识 | 对应特征 | 粗糙度 | 金属度 | 微起伏强度 |
|---|---|---:|---:|---:|
| plaster | 粉刷细砂、柔和漫反射 | 0.91 | 0 | 0.004 |
| concrete | 矿物骨料、浅孔隙 | 0.83 | 0 | 0.012 |
| paving | 错缝铺地、窄灰缝、块面色差 | 0.78 | 0 | 0.008 |
| road | 连续道路、细骨料 | 0.94 | 0 | 0.005 |
| turf | 草叶细粒、疏密变化 | 1 | 0 | 0.006 |
| foliage | 叶脉、克制的蜡质柔光 | 0.74 | 0 | 0.001 |
| soil | 暖褐土色、松散土粒 | 0.98 | 0 | 0.021 |
| bark | 纵向纤维、浅裂纹 | 0.95 | 0 | 0.018 |
| stone | 晶粒、矿物色差 | 0.72 | 0 | 0.014 |
| sand | 暖砂色、细颗粒 | 0.97 | 0 | 0.009 |
| rubber | 运动面层、低光泽细颗粒 | 0.86 | 0 | 0.004 |
| paint | 连续色面、柔和漆膜高光 | 0.44 | 0 | 0.0004 |
| metal | 定向拉丝、集中反射 | 0.26 | 0.86 | 0.0003 |
| painted-metal | 漆膜与金属边缘高光 | 0.33 | 0.28 | 0.0003 |
| glass | 冷青玻璃、局部场景反射 | 0.09 | 0 | 0 |
| water | 细波纹、天空与建筑倒影 | 0.12 | 0 | 0.026 |
| fabric | 经纬细纹、柔和绒光 | 0.97 | 0 | 0.0014 |

材质差异必须同时体现在表面结构及光照响应上，不能只换颜色或随机种子。纹理应可重复生成：当前使用 256 × 256 程序图，颜色乘子与高度／粗糙度数据按线性数据处理，并启用 mipmap 及硬件允许范围内的各向异性过滤。

普通表面使用世界米制 UV，纹理密度随物体尺度保持一致；叶脉使用叶片原生 UV。各类纹理的米制周期、清漆、绒光、透明度和反射系数集中在 `surfaceProfiles`，不得散落到各建筑适配器中。当前玻璃／水面透明度为 0.88／0.96，关闭深度写入及普通实体投影；不能把实体墙、窗栅、门扇一起透明化。

### 4.3 颜色与明暗

- 原有 22 组 Canvas Ramp LUT 是共同色彩来源，在对应色系内插值、调整饱和度；不能为单栋楼另起一套互不关联的颜色或曝光。
- LUT 提供色彩来源，最终仍由物理材质响应光照；不得恢复覆盖物理明暗计算的固定三档着色。
- 粉刷墙保持暖灰／米白，混凝土较中性；玻璃和水面略偏冷青；绿植区分草地、叶片及深浅层次；种植土和树皮使用原色板中的暖褐色。
- 看远景时先读出建筑体量和校园层次；看近景时再读出材质颗粒、叶脉和接缝。禁止过强噪点、脏污或高光盖过建筑形态。
- 配色验证必须使用共同日光设置和相同机位，不能以单独给新建筑增加灯光来制造“材质更好”的对比。

## 5. 光照、反射与深度

沿用 Vanilla Three.js、TypeScript、Vite、WebGL2。标准表面使用 MeshPhysicalMaterial；自定义着色仅补充 UV 等必要行为，保留物理光照计算。

| 项目 | v1.0 共同设置 |
|---|---|
| 输出／色调映射 | sRGB 输出；AgX；曝光 1.07 |
| 日光 | 颜色 #fff0d9，强度 4.2；方向 normalize(145,260,-215) |
| 程序天空 | turbidity=2、rayleigh=1.25、mieCoefficient=0.005、mieDirectionalG=0.8 |
| 环境／背景 | 天空 PMREM；环境强度 0.20；背景强度 0.86、模糊度 0.30 |
| 阴影 | PCFSoft；初次加载宽度小于 700 时 2048，否则 4096，并受设备上限限制 |
| 局部反射 | 当前四处校园静态采样，单面分辨率 256，上限受设备能力限制 |
| 深度模式 | 支持 EXT_clip_control 时反向深度；否则使用对数深度回退 |

阴影必须随相机范围聚焦，并在几何、显隐、剖切等变化后失效更新，不能每帧无条件重拍静态校园。按共享模块处理偏移：世界米／阴影像素记为 t，normalBias=max(0.025,0.9t)；bias 的绝对值为 max(0.000035,t/720)，反向深度取正，对数深度取负。不得只切换深度模式而遗漏阴影比较方向。

反射应采样实际校园，不用外部照片伪造周边建筑。新增建筑须检查探针位置及所属区域映射；现有四处位置并不是覆盖后续所有批次的固定配额，不能盲目把远处新建筑归入默认主楼探针。反射采样应在模型和材质完成后进行，采样时隐藏玻璃／水并可靠恢复可见状态。

当前局部反射为静态近似，不具备光线追踪、视差校正或多次光照反弹，也不随剖切实时重拍。交付不得冒称已实现这些效果。兼容回退仍可能出现少量近景点状接缝；检查与说明应如实保留。

后续场景适配器按以下顺序接入：

1. 根据证据与现有空间生成真实构件，记录 owner／facility、role、shape、part id 与证据标记。
2. 通过共享几何辅助函数建立细节，通过 `surfaceMaterial(mats[part.row], part.role, part.shape)` 获取表面；新增角色先核对语义映射。
3. 实例化和合并按角色、色板、实际材质及必要尺寸区分；叶片原生 UV 与世界 UV、透明与不透明表面不能错误混批。保留拾取和剖切所需元数据。
4. 完成场地与旧构件替换后，执行表面归类、实际三角面 BVH、局部反射采样及阴影失效更新。克隆材质使用共享函数，保留着色钩子与缓存键。
5. 检查新建筑与已完成建筑同框的效果，再完成本批通行与画面验证。不得另建一套仅供截图使用的高精度场景。

## 7. 性能与验证标准

### 7.1 性能处理原则

优先使用实例化、合批、材质／纹理复用、静态阴影缓存及实际几何 BVH，保持已完成的可见精度。优化须同时记录几何和渲染成本，不把 draw calls 下降写成面数下降，也不把单帧提交三角面数混同于全场景可见模型总数。

第二轮参考值：3,297,824 个可见模型三角面、109,517,856 字节几何缓冲、全景 1,481 次稳态绘制调用。这些是现有场景的比较点，不是新建筑必须维持的总量上限。新增批次应说明增加的几何、纹理、反射与初始化成本；不能保证所有设备恒定 60 FPS。

### 7.2 按影响范围检查

| 改动范围 | 必需证据 |
|---|---|
| 文档 | 链接与参数一致性；无需重跑场景构建或浏览器回归 |
| 局部构件／单栋模型 | 构建；相关几何／语义测试；该构件近景、建筑中景、与邻楼同框；受影响入口与路线的实际几何检查 |
| 共享材质、色板或日光 | 构建及相关测试；六个既有固定机位与新批机位对照；窄屏；反光、纹理尺度、色彩和阴影检查 |
| 深度、相机或共享场景初始化 | 上述相关检查，加顶视／主轴正交机位及反向深度／对数回退；确认真实启用的模式 |
| 初始分辨率／设备分支 | 在目标视口重新加载检查；仅从桌面缩窄窗口不能证明初次加载的移动分支已经执行 |

实际画面需检查轮廓棱角、倒角拉伸、漏光、纹理重复与摩尔纹、点状接缝、阴影条纹、玻璃排序以及布局溢出。脚本无错误不等于美术检查已完成，必须查看对应截图。

通行检查包括支撑面、踏步衔接、头顶净空及门洞宽高范围；不能只用一条中心射线代表整个入口。受影响的已认可几何不变量必须复核。未受影响的历史批次不因局部修订而反复全量回归。

浏览器报告必须记录查看器 SHA256、浏览器／GPU、视口、请求与实际机位、深度模式、控制台／WebGL 错误、几何统计和测试范围。性能使用相同设备、视口、机位，预热后至少采样 60 帧，报告中位数及 P95；模拟回退与真实设备检查须区分。

### 7.3 交付清单

- [ ] 标准版本及本批范围明确，偏离项有原因、画面和验证记录。
- [ ] 真实空间、已认可入口及证据分类得到继承；新增 H 参数可追溯。
- [ ] 有效几何细节满足同尺度基准，平面和通行接合保持精确。
- [ ] 新角色与材质匹配正确，近景可辨材质，远景与既有校园色彩一致。
- [ ] 已复用共同材质、日光、深度和反射模块，新增探针归属正确。
- [ ] 按影响范围完成构建、测试、实际通行与截图检查，记录未解决问题。
- [ ] 源码、离线查看器、截图和报告对应同一产物；保留 SHA256 与复现命令。
- [ ] 工程通过与用户认可分别记录，不自动修改建筑批次 acceptance 状态。
