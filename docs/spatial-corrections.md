# 总平面空间修订记录

版本：v0.5  
日期：2026-09-09  
状态：校友确认，等待同期照片／测绘进一步细化

本文件记录对现有总平面和后续 3D 模型的硬约束。目标是**在原有总平面基础上修正关系，不重新发明校园布局**。

## 本轮运动区修正

### 1. 篮球场与跑道

现有文件中“篮球场与跑道平行”仍不充分。

正确关系应为：

- 篮球场保持 **3×2，共六片**；
- 六片篮球场组成的整体长轴与相邻跑道方向平行；
- **篮球场与跑道紧贴、直接相邻**；
- 二者之间不应出现道路、绿化缓冲、广场或无关建筑；
- 后续总平面、碰撞、地面铺装和 Web 3D 模型必须使用同一条边界关系。

这是一条拓扑约束，比当前缺失的精确米制尺寸优先级更高。

### 2. 跑道图面左侧体育辅助用房

跑道图面左侧存在一组与体育教学直接相关的建筑／房间。校友记忆确认的功能包括：

- 健身、锻炼及相关器材空间；
- 体育老师办公室；
- 运动器械／体育器材存放空间。

本阶段统一称为 **“体育辅助用房组”**，但这只是项目内部的工作名称，不代表历史正式楼名。

目前不应擅自确定：

- 每个功能究竟是独立房间还是共享大空间；
- 房间之间的准确分隔；
- 门窗数量和朝向；
- 建筑具体长度、进深、层数；
- 与跑道之间的准确米制距离。

这些细节在没有同期照片、平面图或进一步校友草图前必须标为 `pending`。

### 3. 音乐教室与体育辅助用房必须分开

音乐教室仍满足两项既有条件：

1. 位于跑道边；
2. 位于体育馆后方。

音乐教室**不能因为同样靠近跑道，就与本轮新增确认的体育辅助用房组画成同一栋泛化建筑**。总平面和 3D 模型必须保留二者作为两个独立对象，直到更高质量资料证明具体连接关系。

## 后续总平面修改要求

下一版总平面必须在**原图基础上增量修改**：

- 不整体重排已确认的设施；
- 维持六片篮球场；
- 将篮球场整体移动／校正到与相邻跑道直接贴合；
- 在跑道图面左侧恢复体育辅助用房组；
- 对体育辅助用房标出三个已知功能类别，但房间边界未知时使用虚线或“待核”标记；
- 保持音乐教室位于跑道边和体育馆后方，并与体育辅助用房组视觉上明确分离；
- 所有新修正同步更新 Web 3D 模型坐标与设施元数据，避免“PDF 对了、模型仍错”。

## 验收检查

运动区只有同时满足以下条件才算通过本轮校正：

- [ ] 六片篮球场为 3×2；
- [ ] 六片篮球场与相邻跑道平行；
- [ ] 六片篮球场与相邻跑道紧贴；
- [ ] 两者之间没有被错误插入无关空间；
- [ ] 跑道图面左侧存在体育辅助用房组；
- [ ] 体育辅助用房元数据记录健身／锻炼、体育教师办公室、运动器材三个功能；
- [ ] 音乐教室仍在跑道边＋体育馆后方；
- [ ] 音乐教室与体育辅助用房组没有被误并；
- [ ] 未知尺寸与分间均显式标为待确认。

机器可读版本见 [`../data/spatial-constraints.json`](../data/spatial-constraints.json)。
