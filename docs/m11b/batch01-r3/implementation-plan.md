# B01 R3 修复范围与实施记录

基底：main 0b000a17ac1f507886fda56d7119312bcbaa5313。问题 #29。此前仅完成核定和生成式沟通图，不等于R3模型修复。本次提交实际几何、测试、运行时接入及浏览器验证链。

## 已确认结构
两端门在朝操场的正面退让处，不在山墙；一层门廊依靠五层主体，门在内退正面墙上。旁边主体墙前伸超过门罩，不是短U形侧板；左右入口整体对应但单个入口周围不对称。中央广播站等功能区略有弧度。

## 实施
独立 b01-r3-core.mjs 从R2纯模型继承非目标构件。只裁切15端部前侧楼板/外墙，重建两处门罩、两方柱、内退门洞、邻窗、三级踏步与前伸的五层墙。封闭错误东山墙外门，保留西侧逐层厕所桥口。原东侧道路仍是外围到达点，新局部地坪沿外缘转向前门，不删除其边或缩路。

局部坐标以主楼(73,224)为中心。原正面Z=-7；入口内墙Z=-5；主体前伸墙Z=-9；门罩前缘Z=-7.3。两入口X=±46.4；三级台阶总升高0.45m，踏面总长0.96m；入口平台不改变主楼楼层标高。仅两处入口附近用有限范围地坪衔接低端，不将整个前坪或运动区抬降。上述数值为H。

中部弧面解释为水平平面上的浅外鼓圆弧，8.8m宽、弧矢高0.35m H；中央最前点保持Z=-8.8，中轴不漂移。墙面、楼板、檐口/屋盖使用同一曲线，真实开窗，不套用现代新楼大拱门。
