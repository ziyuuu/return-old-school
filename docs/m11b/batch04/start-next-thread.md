## 四、统一模型与美术标准

执行 `docs/model-rendering-standard.md` v1.0，并在交付中记录标准版本及偏离项：

- 模型优化指提高有效几何精度；复用实际米制倒角、同尺度曲面基准及叶片实现，不擅自减面，也不细分平墙凑数量。
- 保留原22组Canvas色板、柔和低饱和风格；复用17类表面工厂，按role/shape分清玻璃与框栅、楼板与金属、土壤与叶片。
- 统一PBR、AgX、日光、天空和局部反射；不为每栋楼另建一套光照与配色。新增建筑检查反射探针归属，不能盲目落入旧默认区域。
- 保持反向深度／对数回退及对应阴影偏移方向；不引回点状接缝或远景阴影条纹。
- 不用外部照片贴图，不新增bloom、暗角或景深；照片只用作证据和审阅对照。
- 渲染、拾取和当前通行检查使用真实模型；用实例化、合批、缓存和BVH管理成本，保留元数据与真实开口。
