## 2. B05 范围

这是 M1.1-B 最后一批建筑外壳，重点补齐此前四批未完成的校门、体育和生活附属建筑：

- 主校门与校园侧门：门架、门柱、门卫/值班外部体量及与现有入口道路的真实衔接。
- 风雨直跑道：棚顶、柱列、侧向开敞关系，以及与篮球场紧贴的空间关系。
- 体育辅助用房：保持已知的低矮单层体量，核对入口、屋盖和运动场侧关系。
- 宿舍、家属区及其他生活建筑：在已登记位置和体量基础上深化外观、屋顶、公共入口和必要附属体量；不制作私人住宅完整内部。
- 按 01—28 设施登记逐项复核此前 B01—B04 尚未覆盖的建筑外壳，补齐明确遗漏。

主席台、田径场、后缘跑道、沙坑、道路等已建立设施只做必要建筑衔接，不重新布局。不要把树木、密集生活物件、完整室内或正式人物玩法提前塞进本批。

## 3. 证据规则

先核对设施登记、累计运行布局和真实照片。优先使用 2006—2010 年照片及项目已有证据记录；身份、年代、用途不确定时保留 U/H，不编造结论。

缺图立面允许可替换 H 参数，但必须与已有轮廓、道路、高差和相邻建筑一致，并在 evidence 中说明依据。认可不把 H 参数自动转成测绘事实。

## 5. 建模与渲染

遵守统一标准 v1.0，复用共享色板、材质、日光、天空、反射、深度和 BVH 模块。提高真实有效几何精度，不以细分平墙凑面数；不同建筑必须有各自轮廓、屋盖、窗洞和入口特征。

新增建筑检查反射探针归属。真实开口必须保持拾取/通行语义。继续禁止外部照片贴图、bloom、暗角和景深。
