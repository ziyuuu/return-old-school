## 2. B05 范围

这是 M1.1-B 最后一批建筑外壳与主要校园固定场地构件补全，重点补齐此前四批未完成的校门、体育、生活附属建筑，以及对校园识别和空间组织具有决定作用的室外固定设施：

- 主校门与校园侧门：门架、门柱、门卫/值班外部体量及与现有入口道路的真实衔接。
- 风雨直跑道：棚顶、柱列、侧向开敞关系，以及与篮球场紧贴的空间关系。
- 体育辅助用房：保持已知的低矮单层体量，核对入口、屋盖和运动场侧关系。
- 宿舍、家属区及其他生活建筑：在已登记位置和体量基础上深化外观、屋顶、公共入口和必要附属体量；不制作私人住宅完整内部。
- 按 01—28 设施登记逐项复核此前 B01—B04 尚未覆盖的建筑外壳，补齐明确遗漏。
- 校园石/纪念石：核对真实历史位置、朝向、基座、尺度关系及与道路/绿化/建筑的相对位置。文字内容若证据不足，不编造。
- 篮球场固定设施：篮球架、篮板/篮筐、必要支撑结构，以及篮球场周边护栏/围网、门洞与通行缺口；应与已认可篮球场标高和边界一致。
- 足球与田径场固定设施：足球门及其在田径场内场的真实位置、朝向和尺度关系；不得为对称或美观随意重排。
- 主席台：核对并恢复主体台座、顶棚/栏杆/台阶/主要开口等外部识别特征及其面向操场的真实关系。已有位置原则上不移动，除非新证据明确证明登记错误。
- 升旗台/旗杆区：恢复真实位置、基座、台阶/围边、旗杆数量和与主轴、主席台、教学楼的关系；不得把现有主轴改成新设计。
- 其他对 2006—2010 校园识别有强作用的固定场地构件，如明确可证的围栏、挡墙、场边门、看台边界、球场隔离设施等，应在本批一并查漏补缺。

### 植被边界

B05 不做全校园“景观精装”，但不能完全推迟植被。凡会显著影响历史空间轮廓、视线、建筑遮挡和校友辨识的主要植被，应在本批恢复：

- 有照片或多视角证据支持的成排行道树、操场/篮球场边界树阵、入口及主要道路节点的大树；
- 明显界定空间的主要绿篱、成片乔木/竹丛或大型花坛边界；
- 与校园石、主席台、升旗台、校门、篮球场等固定构件存在明确空间关系的特征植被。

树种、精确树龄、树高和树冠缺乏证据时保留 H，不凭现代校园现状反推。零散灌木、花草、密集生活化绿化、精细园艺配置及大量小型植物仍留到 M1.2。

田径场、后缘跑道、沙坑、道路、既有球场标高与 B01—B04 已认可建筑位置原则上不重新布局；主席台、升旗台、校园石等若已有占位模型，则以真实照片和累计布局核对后深化或校准，而不是另造新版本。不要把完整室内或正式人物玩法提前塞进本批。

## 3. 证据规则

先核对设施登记、累计运行布局和真实照片。优先使用 2006—2010 年照片及项目已有证据记录；身份、年代、用途不确定时保留 U/H，不编造结论。

对校园石、篮球架、足球门、护栏、主席台、升旗台和主要植被，必须优先核对“位置、朝向、相对距离和遮挡关系”，不能只做一个相似模型后随意摆放。

缺图立面或不可见固定构件允许可替换 H 参数，但必须与已有轮廓、道路、高差、场地边界和相邻建筑一致，并在 evidence 中说明依据。认可不把 H 参数自动转成测绘事实。

## 5. 建模与渲染

遵守统一标准 v1.0，复用共享色板、材质、日光、天空、反射、深度和 BVH 模块。提高真实有效几何精度，不以细分平墙凑面数；不同建筑和固定设施必须有各自轮廓、结构和历史特征。

新增建筑与大型固定设施检查反射探针归属。真实开口必须保持拾取/通行语义。篮球场护栏/围网、主席台栏杆、球门与篮球架等细杆件应采用适合的真实几何/实例方式，不用大块透明平面冒充。继续禁止外部照片贴图、bloom、暗角和景深。

主要植被延续共享植被材质和几何体系，树冠/树干尺寸必须服务真实空间遮挡，不得用高密度随机散布掩盖位置证据不足。

## 6. 通行与验收

每个主要公共入口至少具备真实开口、门前落脚面及与现有路网的可解释连接。风雨跑道和校门尤其检查实际净空、柱列间距和路径连续性。

- 主要树阵和大树不得错误封死道路、门洞或已认可视线通道。
