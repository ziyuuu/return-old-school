# 旧主楼证据判断

本次继续使用同一组已取回照片，不把复看说成新获得多份证据。

1. 《100张旧照片》主教学楼段明确区分旧楼与新楼。搜狐原发布2018-03-12：<https://www.sohu.com/a/225387012_391114>；新浪转载：<https://k.sina.com.cn/article_6430641585_17f4bcdb1001003x9v.html>。同一文章只算一组。发布年份与供图者毕业年份均不能直接当作每张图片拍摄年。
2. S03-040左上子图：浅色窗墙、成组窗洞、平直长屋盖与小圆顶轮廓可见（P）。将其用于旧楼外壳；遮挡区域、窗宽和圆顶具体构造由H补全。
3. S03-038：露天平台、左侧门窗墙与外缘围护可见（P）；文章称旧主楼四楼有大后坪（R，作者校友回忆）。因此在第四层后侧留出露天平台，不把它套到新楼，也不为露台移动整栋楼。平台尺寸及未见面按工作参数补全。
4. 现代操场四联图中的橘红色教学楼不用于旧楼立面。它在A阶段只帮助判断操场边界/高差，不能替代旧楼照片。
5. 厕所连续楼体、逐层完整楼板、桥口、两端门和前廊是用户已确认A关系。后侧高窗、收边和栏杆构造作为H外壳细化；左右只标A/B，不臆定男女端向。

照片原件不作为场景贴图，也未因本次公开代码而重新发布。来源URL、用途和限制保留在证据清单。数字参数独立存档，资料空缺不重新阻断制作。
