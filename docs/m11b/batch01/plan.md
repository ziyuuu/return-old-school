# M1.1-B 第一批｜旧主教学楼、厕所与连接桥

前置：M1.1-A P3/P4 已获校友认可。Issue #27；本批完成工程检查后进入 REVIEW_PENDING，不继承A阶段的校友批准。

## 本批落地

15旧主楼：保留98×14的冻结占地与四层基准，替换原简化体块。用墙片分割形成真实门窗洞，添加窗框、窗台、楼板、层间线脚、屋盖及小圆顶轮廓。正面按旧照片浅色封闭窗墙处理，不做现代橘红色大拱门，也不把旧灰盒外廊的示意柱列当作历史立面。墙后保留通长交通带，西端转入桥口。

四楼：后墙在原占地内部退让形成约4.2米深的露天后坪，接入门洞和外侧围护齐全；不外扩建筑占地。露台存在由旧照片和回忆支持，展开长度、门位置和圆顶细部为工作补全。

25厕所：直接继承R4完整连续楼体、四幅完整楼板、每层前廊、两端朝主楼的门与中部护栏缺口。补高窗和屋面收边，不拆成男女两栋，不指定未知的男女端向。连接桥保留四层端点与宽度，增加上层实体栏杆，首层留横向穿行。

## 不变项

所有设施编号和建筑X/Z、data/m10和baseline/m1.0-r4不变。沿用P3/P4入口纵坡、下沉田径场、抬高篮球场、三旗前坪和食堂下层小卖部。主楼后门、桥下路通图书馆，体育馆正门、观赛梯、音乐楼贴体和环路保留。

## 模型组织

`input.json`保存工作参数；`batch01-core.mjs`生成可测试的楼层/墙体/门洞/路线；`batch01-scene.ts`按楼层分组渲染，重复墙片与窗框用InstancedMesh；`resolved-buildings.json`可复算全部构件。建筑颜色沿用Canvas Ramp LUT，无外部照片贴图或后期掩饰。

## 验收

继承仓库329项旧回归；补地形基底和建筑外壳检查，主动封门、移桥、缺板、堵护栏、覆盖露台并验证失败。真实Chromium检查8条楼层门口路线、实际支持面、门洞、露台、桥下路和场地基底。交付Viewer、同数据图、真实截图Review和源码Workspace。

## 阶段边界

本批是建筑外壳，不是完整室内；教室内部划分、室内楼梯系统、家具、管线等后续细化。自由相机不是角色控制器。下一批才是体育馆＋音乐楼进一步外壳深化。
