## M1.0 冻结规则

1. `baseline/m1.0-r4` 作为参考基线，不承载后续日常开发。
2. M1.1 开始后，不因精模便利而移动已确认建筑、改写道路或拆除已确认连接。
3. 只有 baseline-breaking evidence 才能重新讨论冻结项，例如可靠新资料证明主要建筑位置、核心道路或关键设施关系存在实质错误。

# M1.1 — 全校园体块、道路与高差校准

**状态：NEXT / NOT STARTED。**

M1.1 的任务不是精雕建筑，而是把 M1.0 的平面与基础体块升级为可信的三维校园空间，使建筑高度、地坪、高差、道路、平台、楼梯和坡道之间形成连续关系。

## M1.1-A：Campus Terrain / 地形与地坪

### 工作范围

- 建立全校园地面网格与分区地坪。
- 明确主门、侧门、主路、操场、篮球场、风雨跑道、泳池、体育馆平台、教学楼前后场地、图书馆、科学馆、食堂和家属区之间的高差。
- 对照片可见的台阶、挡墙、路缘、坡道进行 H/P/A 分级。
- 没有测绘数据时，通过台阶数量、人体尺度、门槛、栏杆、窗台和相邻建筑首层关系推定工作高程。

### 退出条件

- 主要区域不再处于同一无意义平面。
- 道路和场地相接处无明显断层、穿插或悬空。
- 每个主要高差都有来源或明确 H 假设。

## M1.1-B：Building Massing / 全校园建筑体量

### 工作范围

- 01–28 设施除明确未定位对象外，建立与资料相符的多体块建筑外壳。
- 校准楼层数、工作高度、屋顶类型、入口平台、连廊和附属体块。
- 体育馆、音乐楼、主教学楼、厕所、长雅楼、科学馆、旧图书馆、食堂、家属区等不再用统一盒子表达。
- M1.0 已确认的设施位置和关键拓扑不能为了体量制作而移动。

### 退出条件

- 校友在主要机位能够凭空间轮廓识别区域。
- 建筑间不发生无依据穿插。
- 所有推定高度与已验证事实分层保存。

## M1.1-C：Access & Circulation / 入口与通行

### 工作范围

- 把主要门、后门、连廊、平台、楼梯、坡道和穿行口做成真实几何开口。
- 校核主门—校园、侧门—侧路、主楼—厕所—旧图书馆、主楼后门—图书馆、长雅正门、体育馆—音乐楼贴体等关系。
- 保持 R4 主干路宽连续、三处补充短路和已删除错误道路状态。

### 退出条件

- 主要步行路线均存在真实地面和开口，不穿实心体块。
- 楼梯/坡道能够解释高差，不用相机穿越解决。
- 自动路网检查和实际浏览器多机位检查同时通过。

## M1.1-D：Alumni Spatial Review / 校友空间复核

### 固定机位

至少包括：主门外、主门内、侧门、操场四角、主教学楼前后、厕所连接、旧图书馆、体育馆正/侧、球场看馆、风雨跑道、音乐楼、食堂、科学馆、长雅正门、家属区。

### 退出条件

- 主要路线和空间距离不再出现显著记忆冲突。
- 新反馈若只涉及细节，则进入 M1.2；只有结构性证据才回看 M1.0。

# M1.2 以后 — 建筑与环境深度复原

在 M1.1 稳定的三维空间上逐栋进入高精度制作：校门、体育馆、主教学楼和运动区优先，其后为音乐楼、体育辅助用房、科学馆、长雅楼、旧图书馆、食堂、办公实验区域、宿舍公共区域等。

进一步加入窗框、门洞进深、瓷砖分格、栏杆、空调、排水、管线、公告栏、课桌椅、灯扇、体育器材、树木、树池等校园识别细节。室内必须与外壳开口和楼层一致。

---

# M2 — 全校园夜间中式梦核

只在 M1 完成后的真实校园基底上增加可逆的灯光、材质、空气感、声音和空间异常覆盖层。夜层不得改变历史基底的建筑坐标或真实拓扑。

当前不制定具体谜题、追逐、怪物 AI 或章节长度。

# M3 以后 — 互动与游戏内容

在校园复原与夜间空间完成后，再设计循环梦境、幽魂、怪物、交互与叙事。不得为了玩法便利改写已冻结的真实校园关系。

# 文档原则

A = 校友明确确认；P = 照片可见；R = 类比资料；H = 工作推定。采用米制工作单位不等于测绘认证。所有历史版本和推定必须可追溯、可替换。
