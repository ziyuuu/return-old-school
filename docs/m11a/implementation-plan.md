# M1.1-A 落地计划

输入：[调研结果](research-findings.md)。冻结水平基线仍为R4；冻结分支不写入。

## 工程结构

1. `data/m11a/terrain-input.json`：相对主门0m的地坪、建筑入口抬高与局部台阶；所有尺寸H，measured=null。独立保存R4布局快照和文件哈希。
2. `terrain-core.mjs`：无Three依赖的地坪高度查询、平整台地、建筑锚点、分段道路纵剖与楼前台阶数据。两组建筑03/24、15/25的垂直锚点强制一致。
3. `terrain-scene.ts`：真实地形网格、贴地路面、局部门前台阶/平台/基础；动态开关只改高度和可见性，不改冻结X/Z和路网。对照关闭时恢复原始R4体块/路面。
4. 原查看器：增加地坪开关、入口台阶机位、导出工作标高与纵剖；路线巡览眼高相对地面，而非全程绝对y=1.7。
5. 导出与验证：同一参数生成标高表/纵剖/三维几何，但用实际浏览器射线独立检查支撑与净空，避免仅凭参数互相证明正确。

## 初版工作方案（全为H，不是测量）

|区域|地坪/局部入口安排|
|主门、侧门|相对0m，入口分路关系不变|
|球场、棚跑道、田径场、后缘直段|平整0m；不让缓坡穿过运动平面|
|体育馆/音乐楼|共同首层+0.60m；外部入口各4级工作台阶，本体仍直接贴合|
|前庭/主楼厕所组团|前庭+0.30m，主楼/厕所/桥下区域+0.45m，道路温和过渡|
|长雅楼|周边+0.45m，入口另抬+0.90m，6级×0.15m工作值|
|旧图书馆|周边+0.45m，入口另抬+0.45m，3级工作台阶|
|食堂/家属区|中性+0.20m，保留食堂原有层间关系，不将入口上楼误作整体地形|
|科学馆等未明区域|中性地坪/温和接路，不人为增加深沟陡坎|

旗台照片可见局部平台，初版仅在现有前庭内细化工作平台，不改变14位置。不能套用CMIE新馆下沉庭院或将6–7m边界高差放入全校。

## 验收门槛

A. R4全28项设施水平定位/占地、道路连接/宽度、主楼逐层连接、音乐楼贴体不变；22仍未定位。
B. 已有118项R4回归继续通过；新增地坪校验和主动错误注入（倾斜球场、错开桥层、错台阶高、恢复被删路等）。
C. 对每条已登记道路分段检查坡度和实际渲染路面高度；保持指定主路宽度。道路允许H纵坡，但不能出现无记录断崖。
D. 对每一门前台阶检查踏面支撑及上端门洞/平台；对厕所四层检查共同抬升后仍可桥接两端门。
E. 对照开关不得累积位移、重复建几何或破坏楼板；HTTP和独立HTML启动、导出、机位和手机画布尺寸检查。
F. 交付真实WebGL截图、查看器HTML、源码/数据包、研究和落地文档、回归清单。工程通过不代替校友对H高差方案的审阅。

## 边界及后续

本阶段不制作完整台阶自动攀爬/物理角色，不新增室内路线；此部分属于M1.1-C。旗台栏杆造型、铺装磨损、完整雨排系统和树种属于后续环境精化。M1.1-A完成工程实现后仍标`IMPLEMENTED / REVIEW_PENDING`，不自动关闭整个M1.1。
