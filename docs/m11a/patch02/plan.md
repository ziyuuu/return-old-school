## 事实与假设

A：校友明确指出坡道更陡、正门服务主路、前坪、侧向绕馆道路、左侧楼梯通往观赛层。P：新照片能看到前坪、通长平台、侧梯入口、内凹窗带和白色折面。照片本身不能证明看不见的后方环路细线形、标高和楼梯精确级数。

H：20m/1.00m坡道；42×42m占地沿用旧工作方案；最高19.20m、观赛层4.20m、入口0.60m等都是从合理层次出发选择的可替换数值，非图像测量结果。

## 环路方案

环路沿馆北侧绕到西侧，再从音乐楼、泳池和池厕南边的现有球场前通行带返回主路；东侧借用主路闭合。它环绕的是体育馆及贴体音乐楼的外缘，不在两栋楼之间开缝。西、后侧道路的具体线形是H；本轮不声明消防道路或车辆转弯半径合规。

主路在馆正门前增加一个分段路口，短路穿过前坪到入口台阶。不能把原北侧"gym-entry"继续保留成门。侧门独立入口、已删除长雅绿色路、黑线短路以及主干宽度保持。

## 工程顺序

独立配置 → 生成当前有效布局/地坪 → 重建03几何 → 前坪与闭合路 → 逐步几何探测 → 多机位实机截图 → 导出HTML、地图、剖面和回归清单。所有运行颜色继续使用程序Canvas Ramp LUT；运行时不加载照片或字体，不使用后期效果。

## 技术依据与限制

使用 Three.js 官方 BufferGeometry 与 Raycaster 机制。射线测试验证模型中实际表面和开口，不认证真实建筑尺寸。注意射线默认只能检测朝向射线的三角面，屋壳需有正确绕序与封闭厚度。

- https://threejs.org/docs/pages/BufferGeometry.html
- https://threejs.org/docs/pages/Raycaster.html

本轮不加入人物物理、怪物、玩法或夜景。M1.0参考分支不修改；本次批准的局部例外也不意味着全校重新解冻。
