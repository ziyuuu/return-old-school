# M1.1-A 调研计划（先研究，再实现）

日期：2026-09-10。范围：校园地形、道路、地坪与高差。不含夜景、玩法、建筑精模或完整角色控制器。

## 1. 输入和不可变项

以 M1.0 R4（已验证源码64360bb、冻结参考baseline/m1.0-r4）为水平空间基准。不移动任何已定位设施的X/Z、占地、朝向；不改道路图的连接、既有宽度和校友确认的建筑连接。22仍未定位。地形数据独立保存，不写回冻结分支或把R4的0m值冒充实测。

## 2. 调研问题

|区域|寻找的线索|禁止的推断|
|主门/侧门/主路|门槛、路缘、坡向、路面连续性|不能仅凭透视判断整条路的高差|
|田径场/后缘跑道/前庭|看台、台阶、边缘挡墙和从主楼向操场的俯视|不能以常见运动场规格证明雅礼的绝对标高|
|体育馆/音乐楼/棚跑道/球场|入口平台、外梯、裙房与球场同框|不使用新体育馆设计覆盖旧馆|
|主楼/厕所/图书馆|楼前楼后地坪、桥下通行、台阶和基础|不能破坏厕所逐层平接和每层楼板|
|长雅楼/科学馆/食堂/家属区|门前台阶、坡道、建筑基础及铺装|不采集私人住宅内部|

## 3. 采集顺序

先检查已有研究照片/台账和校友确认；再核查公开摄影原页、学校原站、设计单位与原作者图片；最后查询地形重建方法的官方技术文档。每张证据注明来源、年代、是否独立、可支持的观察与不能支持的尺寸。失败/无新增也要记录。第三方照片仅供研究，不作游戏纹理或未经授权公开拷贝。

## 4. 决策规则

A校友确认/P照片可见/R方法类比/H工作假设分别保存。同一来源中“看到台阶”和“选取每级0.15m”分列；数值未测则measured=null。证据不足区域保持中性标高，不为显得立体而人为造山。工作标高以主门0为相对基准，不是海拔。

## 5. 研究退出与落地

交付证据表、覆盖矩阵、带范围的工作标高方案和未决项；之后再定落地计划。实现可开关的独立地坪层、同数据高度采样/几何、道路纵剖和局部平台，所有建筑只做对应垂直适配。先检测R4水平不变，再检测道路接缝、可见几何支撑、桥层对齐和独立HTML。保留R4比较入口；没有现场测量不停止实现，也不声称测绘精度。

## 6. 实施完成的定义

必须有真实WebGL运行截图、可下载查看器、源码/数据/文档及回归结果。工程实现通过与校友最终高差验收分开；M1.1-B/C/D不会因A交付而被宣布完成。
