## 3. 图像分类与可测线索

- OLD-DATED：有可核日期的同期图；OLD-ATTRIBUTED：老校友供图但拍摄时间未证实；MODERN：明显改造后；UNKNOWN：无可靠年代。
- 视角分为门外向内、门内向上、坡顶回望、体育馆侧、场内向外、教学楼侧、主席台侧、鸟瞰。说明每条证据看得到和看不到什么。
- 可用线索：路缘消失点、门洞竖线、台阶级数、前坪遮挡、人物/车轮/栏杆相对尺度和地坪交线。人体、车门、门洞、栏杆尺寸均只能作 H/R 尺度先验，不能转写为现场测量。
- 透视图只有单视角且无标定时不能唯一解出高差；保留候选区间及视觉解释，避免伪精确。

## 4. 证据纪律与年代隔离

A = Alumni Confirmed；P = Photo Visible；R = Reference；H = Working Hypothesis。每条证据需来源URL/用户来源、发布时间、拍摄时间及置信说明、视角、可见/不可见、等级、历史几何适用范围、现代参考限制。

现代图仅可支持边界、高差存在和长期建筑关系；不能自动导入现代草坪、铺装颜色、栏杆样式、标牌。未证明2006—2010存在的围护外观采用中性程序化 H 表达，未知项明确保留。一般规范不得冒充该校竣工资料。
