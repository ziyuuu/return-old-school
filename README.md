# 复原雅礼 · Return Old School

以长沙雅礼中学东塘校区为历史空间参考的 Web 校园探索与心理恐怖解谜项目。

## 项目方向

- **白天**：表面正常的现代返校，访谈、观察、收集与交叉验证信息。
- **夜晚**：以 2006—2010 年校园记忆为素材的中式梦核。白夜转换由剧情条件触发，不按现实时间自动轮换。
- **核心**：玩家陷入循环梦境，辨认幽魂的真实诉求，摆脱将所有人固定在过去的不可名状存在。
- **空间**：沿用已有平面图和设施编号，以校友校正与影像证据持续修订；不以生成式图片代替地图、模型或浏览器实机截图。

## 当前状态

仓库已初始化，正在整理 v0.3 的平面修订、网页场景、原创剧本和开发计划。尚未达到全校实测 1:1、完整游戏或发布就绪状态。

本项目是独立创作，不代表学校官方。恐怖事件、角色、死亡与怪物均为虚构，不应被解释为真实校史或真实师生经历。公开资料仅按各自权利条件引用；来源不明的第三方照片不直接收入公开资产目录。
