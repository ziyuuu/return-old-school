# 复原雅礼 · Return Old School

为校庆与同学回忆制作的雅礼中学东塘校区数字复原项目，不是商业游戏。

**校园真实复原 > 模型精度与环境完整度 > 正常白天 > 夜间中式梦核 > 剧情和具体玩法。**

## 当前状态

**M0：COMPLETE — 资料与推定工作基线已关闭。**

**M1.0：COMPLETE / FROZEN — R4 空间基线已冻结。**

**下一阶段：M1.1 — 全校园体块、道路与高差校准，尚未启动。**

M1.0 冻结并不等于测绘级 1:1 已完成。它表示主要设施身份、工作位置、道路拓扑和关键连接已经稳定到可以进入后续三维深度还原；未实测尺寸继续按 A/P/R/H 证据等级管理。

## 冻结的空间基线

- 01–28 设施编号继续作为稳定身份；未定位对象不虚构位置。
- 主门、侧门、校名石按 R4 总图关系冻结；侧门路在入口区域不与主门主路错误直连。
- 六片篮球场为 3×2，与有顶棚的 05 直跑道平行且紧贴；28 体育辅助用房为低矮单层。
- 08 田径场保留操场后缘橡胶直段；23 沙坑采用后缘右端位置；10 主席台采用 R4 上移后的工作位置。
- 03 旧体育馆与四层 24 音乐楼本体直接贴合；不保留外加连接楼梯/连廊的旧假设。
- 25 主楼厕所位于主教学楼图面左侧，每层中部相连；厕所为连续楼体，每层有完整楼板和门前走廊，两端入口朝主楼，桥侧护栏留通行缺口。
- 主楼与厕所之间地面可通向旧图书馆，主楼后门与图书馆保持连接。
- 17 长雅楼采用 R4 工作位置，道路直达正门；错误绿色绕行路已删除。
- 20 家属区采用 R4 右上移动后的组团位置和外部体量；不建立私人住宅内部。
- R4 补充的三处黑线短路和红框主干连续宽度作为当前道路基线。

## M1.0 的边界

M1.0 是**空间骨架基线**，不是建筑精模、完整校园游戏或测绘认证。没有测绘依据的尺寸和坐标仍是可替换工作值；建筑隐藏面、精细立面、完整室内、道路高差、绿化、校园物件、完整人物碰撞均不属于 M1.0 完成条件。

只有出现能够推翻主要建筑位置、核心道路拓扑或设施关系的新证据，才重新讨论 M1.0 冻结项。窗格、局部门位、栏杆、树木、材料、层高微调等进入 M1.1/M1.2 处理，不回滚 M1.0。

## 后续阶段

**M1.1**：全校园体块、道路、地坪和高差校准；主要入口、楼梯、坡道和穿行关系；固定多机位校友复核。

**M1.2 以后**：逐栋高精度建筑、关键室内、绿化和校园物件。

**M2**：在冻结的真实校园基底上增加可逆的全校园夜间中式梦核层。

**M3 以后**：再进入具体互动、循环梦境、幽魂、怪物和玩法设计。

本项目为独立校友创作，不代表学校官方；虚构内容与真实校史、真实师生经历区分。
