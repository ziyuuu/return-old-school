# 复原雅礼 · Return Old School

以长沙雅礼中学东塘校区为对象的 Web 3D 校园复原项目，并在此基础上发展为校庆期间供同学体验的中式梦核恐怖作品。

## 项目优先级

本项目不是商业游戏。当前首要目标是把校园重新做出来，而不是先设计复杂玩法。

**优先级：真实校园复原 > 模型精度与环境完整度 > 现代白天状态 > 夜间中式梦核状态 > 剧情与具体玩法。**

- **M1：全场景深度还原与模型精度优化。** 完成校园室外连续空间、主要建筑高精度外观、关键室内、环境构件和多机位照片校核。
- **M2：全校园夜间中式梦核设计。** 在 M1 的真实校园资产上建立可逆的夜间灯光、材质、声音和空间变体；不提前冻结具体谜题或怪物机制。
- **M3 以后：互动、循环梦境、剧情与游戏内容。** 玩法必须服从已经校准的校园，不为了关卡方便改动真实建筑关系。

## 时间层

- `2006—2010`：历史复原基底，优先使用同期影像、公开资料和校友校正。
- `present-day`：白天“多年后返校”的现代覆盖层，不反推或覆盖历史状态。
- `night-dreamcore`：夜间梦核覆盖层，建立在真实模型之上，不修改基底资产。

## 当前空间约束

- 主教学楼图面左侧存在与教学楼直接连接的独栋厕所；
- 篮球场为 **3×2 六片**；篮球场长轴与其相邻跑道平行；
- **篮球场与这条相邻跑道边界紧贴、直接相邻**；中间不得再插入道路、绿化带或其他建筑；
- **跑道图面左侧存在一组体育辅助用房**，包括健身／锻炼空间、体育教师办公室和运动器材／器械存放空间；分间、层数和门窗继续校核，不能把三种功能写成已确认的三栋楼；
- 音乐教室同时位于跑道边和体育馆后方，**与体育辅助用房分开登记功能**；物理建筑从属及具体连接继续核验；
- 游泳池图面左侧有篮球场／泳池区域厕所；
- 操场主席台位于操场图面左侧；
- 国旗附近有沙坑；
- 校门右侧有校名石；
- 体育馆后续精模依据实拍细化折面壳体、退窗、平台、入口、外梯和内外对应关系。

以上关系以校友校正为当前约束；准确尺寸和房间细节继续通过同期照片、实测或更多校友证据核验。约束数据见 [`data/spatial-constraints.json`](data/spatial-constraints.json)，后续限制与编号冲突见研究入口。不同记录冲突必须登记处理，不能静默取其一。

## 开发原则

- 不用生成式图片代替历史证据、地图、模型或浏览器实机截图；
- 本版二维还原依据图只分析实拍可见部分，不生成未知背面来凑多视角；
- 未知尺寸和结构明确标注，不制造伪精确；
- 关键建筑必须多机位校核，不能只在一张截图里“看起来像”；
- 历史基底、现代覆盖层和夜间梦核层分开维护；
- M1校园漫游版即使没有完整剧情，也应能够作为独立校庆作品发布。

详细计划见 [`docs/development-plan.md`](docs/development-plan.md)。运动区关系说明见 [`docs/spatial-corrections.md`](docs/spatial-corrections.md)。

## 当前状态

项目仍处于空间校核与工作资料阶段，尚未达到全校实测1:1，也不是完整游戏。具体谜题、怪物AI、关卡时长、背包和任务系统均不作为现阶段重点。

本项目为独立校友创作，不代表学校官方。恐怖人物、事件和超自然内容均为虚构，与真实校史、真实师生经历区分。公开资料按各自来源与权利条件引用；来源不明或授权不清的第三方照片不直接作为公开发行资产。
