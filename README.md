# 复原雅礼 · Return Old School

为校庆和同学回忆制作的雅礼中学东塘校区数字复原项目。不是商业游戏。

**优先级：真实校园复原 > 模型精度与环境完整度 > 正常白天 > 夜间中式梦核 > 剧情和具体玩法。**

## 已确认的空间事实

- 主楼图面左侧独栋厕所：**每层连接、门朝教学楼**。草图按T形通道到男女两翼理解；不套用到泳池厕所。
- 篮球场：**3×2六片，与相邻直跑道平行且紧贴**，中间不插道路或绿化。
- 直跑道夹在体育辅助用房与篮球场之间。项目编号绑定05，08继续表示田径环道；这不是历史官方命名。
- 体育辅助用房28：**低矮单层**，有健身/锻炼、体育教师办公室和器材空间；三种功能不等于三栋楼。
- 音乐楼24：**四层独栋**，跑道旁、体育馆后方；不与28合并。
- 草图同一端对应音乐楼、WC和泳池；池畔厕所26位于泳池图面左侧。
- 主席台在操场图面左侧，沙坑靠近国旗区；校门参考视图右侧有校名石。

草图不提供米制尺寸或地理方位。体育馆未画入草图，局部组团与原总图的绝对配准仍标为H推定。

## 允许推定，但不得伪称实测

用户授权：优先检索雅礼自身资料，缺失部分可用公开同类学校/时代标准及合理推定补足。

A为校友确认，P为实拍可见，R为类比参考，H为选定工作假设。音乐楼四层属于A，层高3.8m属于H；不得把两者合并标成已测量。没有实测值的字段继续为空，工作值另表保存。

当前没有全校测绘控制网，也没有全部建筑四面实拍。可继续资料深化和M1前置工作，不再把已确认的层数、厕所逐层连接或所有现场量测作为无限等待的前提。

## 里程碑

- **M1：全场景深度还原与模型精度优化。** 校园完整度与校友辨识度优先；全校园外部、主要室内、绿化及校园物件统一组织。
- **M2：全校园夜间中式梦核设计。** 独立、可逆的夜间灯光/材料/声音/空间覆盖层，不改坏真实基底。
- **M3以后：互动与游戏内容。** 暂不冻结谜题、怪物AI或章节时长。

历史2006—2010基底、现代白天覆盖层和夜间层分别维护。M1校园漫游本身可以作为独立校庆作品。
